# Code of Conduct

We want people to be able to report security problems, question an advisory,
and disagree about evidence without being attacked for it.

Everyone taking part in this project is expected to:

- Be respectful, patient, and constructive.
- Criticize claims and technical work, not the person who made them.
- Keep discussion focused on evidence and the exact package release.
- Accept corrections when new evidence changes the picture.
- Avoid harassment, threats, discrimination, doxxing, and personal attacks.
- Never publish secrets, private data, or information that could put someone at risk.

Maintainers may edit or remove comments, close discussions, or block
participation when behavior harms the project or its community. Serious or
repeated violations may result in a temporary or permanent ban.

To report a conduct concern, contact the project maintainer through the
contact options on the maintainer's GitHub profile. Please do not open a
public issue with private information.
