## Summary

Security consideration when executing project build scripts

## Details

The package's `pt build` command reads the local project's `prepublishOnly` or `prepare` script from package.json and executes it with child_process.execSync. This behavior is part of the build automation workflow and is not, by itself, evidence that the package injects or secretly executes attacker-controlled code. However, running `pt build` on an untrusted project can execute commands intentionally defined by that project's package.json. Developers should treat build commands from untrusted projects as executable code and review the project's scripts before running them.

Observed behavior:
- `pt build` executes the local project's `prepublishOnly` or `prepare` script via child_process.execSync.

Evidence:
- `pt.js` — The build() function reads the `prepublishOnly` or `prepare` script from the local package.json and executes it.
