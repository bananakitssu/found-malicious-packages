## Summary

Malicious typosquat of transformers: PTH loader, credential stealer, cryptominer

## Details

The package 'transfomers' typosquats Hugging Face's 'transformers'. It installs a .pth file auto-executed on every Python startup. The PTH contains decoy 'verified clean' comments, then execs a base64+XOR-obfuscated payload that downloads http://16.78.16.190:7788/lurves-agent.py and runs it as a daemon. Second stage exfiltrates credentials/SSH keys, persists, and mines. Same campaign as openaii (2026-09-openaii). Confirmed MAL-2026-16136. Package removed from PyPI.
