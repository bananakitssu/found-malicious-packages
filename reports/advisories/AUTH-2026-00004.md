## Summary

Malicious typosquat of openai: PTH loader, credential stealer, cryptominer

## Details

The package 'openaii' is a typosquat of the legitimate 'openai' library. It copies the official summary and plants a malicious .pth file that Python auto-executes on every interpreter startup. The PTH payload uses obfuscated exec, anti-analysis comments directed at AI reviewers, downloads a second stage, then exfiltrates SSH keys and cloud credentials, establishes persistence, and installs a cryptominer. Confirmed by OpenSSF MAL-2026-16135 / amazon-inspector / kam193 (campaign 2026-09-openaii). Package removed from PyPI.
